# Pytorch Experiments
Playing around with PyTorch, getting to know the library. Some ideas...

## Typical MNIST number/digit classifier
Can implement both a classic MLP and a CNN and compare the difference in performance between the two. Would be a nice introduction to using PyTorch in the first place and defining different NN architectures.

## Human Face Recognition, Embedded Deployment
Creating a model for use on an embedded device to detect human faces, using a camera module. RT-Thread Vision Board could be useful for this. Train a model using PT and then figure out the industry-standard way of deploying the model on-device. Figure out how to make the most of the inference-oriented hardware/acceleration (vector instructions, SIMD etc...)
